# Libro indioyori
Creación de un libro comercial, adaptado a la realidad y mercado, de un libro base, paèrs e investigaciones académicas


Genera un libro para vender como libro electrónico y físico. 
Investiga cuales son los mejores canales para ambos
Haz un estudio de mercado para que determina el precio ideal, sin abaratarlo, un precio digno
Crea el enfermedad del libro. Letra mono, blanco con negro y detalles con los colores de mi avatar que está en imágenes
Que sea un libro para el mestizo de a pie, que migra del campo a la ciudad y olvida de donde viene.
Para el chicano, para el blanco con familia morena que no se encuentra. Para el afromexicano que no se siente de ninguna parte. 

Este debe ser un exitaso!!
